# 🔐 Biometric Data Purge & Notification System

## 📌 About

The **Biometric Data Purge & Notification System** is a secure web-based data lifecycle management tool designed to automate the monitoring, flagging, and notification of time-sensitive biometric records.

This system simulates enterprise-level handling of sensitive datasets, ensuring secure configuration management, automated milestone tracking, and real-time administrative alerts.

It is built around three core principles:

- **Security**
- **Automation**
- **Reliability**

---

## 🚀 Key Features

- 🔐 **AES-256 Encryption** for protecting sensitive system configurations  
- 🔑 Secure authentication with password hashing workflows  
- ⏱ Timezone-aware monthly milestone detection logic  
- ⚙️ Automated background scripting using Windows Task Scheduler (`.bat` / `.vbs`)  
- 🔔 Desktop-based real-time administrative notifications  
- 🗃 Structured MySQL database architecture  
- 🌿 Git-based version control for tracking security patches and upgrades

## 🎯 Purpose

This project demonstrates secure backend architecture, encryption implementation, time-based automation logic, and system-level scripting integration. It reflects real-world enterprise data management scenarios where data sensitivity, automation, and reliability are critical.
